WHY
  P-020 (LEDGER, rank 20, on PLAN's must-run list): a recency path in attention; its variants are the forget gate,
  stick-breaking, PaTH, Selective Attention and learned ALiBi slopes. T001's toy picked stick-breaking for the 30M test
  from four of them; PaTH was never built, for a build cost (T001 PREREG: "so under Max's rule it goes to Max as a
  question, not a silent cut"). S005 screened the forget gate at 5M. PaTH is the only P-020 variant with no reading
  anywhere in the repo. It replaces RoPE's fixed rotation with a data-dependent product of Householder-like transforms
  between each key and query, so a head can learn where to stop looking back (a recency path is one thing it can
  express; the paper reports gains over RoPE in language modelling at 760M and on synthetic recall and state tracking).
  This screen asks the 5M loss question for it, as S005 did for the forget gate.

THE CHANGE (one flag, with B2's equal-total fit)
  model.path_attn: true (new field; default false, omitted from to_dict when false). Registered form: the released
  layer at its defaults (low-rank w, the short conv on w with kernel 3, no conv bias, no forget gate). In every layer,
  per KV head h and token t, from the attention sublayer input a_t (after attn_norm and norm scaling, as S005's a_t):
    w_t = L2Norm_h(SiLU(DWConv3(U_w D_w a_t))): D_w 192 -> 32 and U_w 32 -> 192, no bias; DWConv3 a depthwise causal
      conv of kernel 3 over the 192 channels, no bias, whose taps read zero across a document start (and before the
      row start on the doc=None path); L2Norm over each KV head's 64 channels, in fp32;
    beta_(t,h) = 2 x sigmoid(v_h . a_t + b_h), in fp32, so beta lies in (0, 2) (one projection v, b per KV head);
    H_t = I - beta_t w_t w_t^T (per KV head, 64 x 64);
    logit(i, j) = q_i^T H_i H_(i-1) ... H_(j+1) k_j / sqrt(64) for j <= i in i's document (the empty product, I, at
      j = i); softmax over j; values, the value residual and the attention gate as BASE.
  q and k are BASE's after QK-norm (kept: the released layer's use_qk_norm option, so the one change is the position
  encoding); RoPE is applied to neither (PaTH replaces it). The order is the paper's equation (attention proportional
  to exp(k_j^T (product over s = j+1..i of H_s) q_i), each H symmetric) and the released decoding step (each new
  token's H updates every cached key in place, and its own key is cached untransformed).
  INIT: D_w, U_w, v and the conv taps normal(0, 0.02), b zero (the released model's _init_weights; 0.02 is also the
  harness's init_std), drawn after every BASE draw (registered last), so every BASE parameter keeps its draw. At init
  v . a_t has SD about 0.28, so beta is about 1 and each H_t is close to a projection: distant keys start attenuated,
  and with no RoPE the arm starts away from BASE's function.
  PARAMETERS per layer 6,144 (D_w) + 6,144 (U_w) + 576 (conv) + 579 (v, b) = 13,443; 8 layers 107,544, so PaTH alone
  is 5,117,677 (+2.15%, outside B2's 2%). B2's equal-total fit, S009's and S010's kind: model.mlp_hidden 465 (from
  488; 23 x 4,608 = 105,984 fewer), total 5,011,693 (+1,560, +0.03%); arithmetic, count_analytic must equal it.
  OPTIMIZER (split_params): D_w, U_w and v are 2-D, so "matrix" (NorMuon), as attn_gate_proj; b "scalar"; the conv
  taps (3-D) "scalar" by name, as Canon's kernels. The authors train every parameter with AdamW; NorMuon for block
  matrices is the harness's rule and is kept (one change).
  PRECISION: w, beta and every Householder product in fp32 under bf16 autocast (the paper names bf16 instability of
  the cumulative product); logits and softmax in fp32; values at the autocast dtype. No beta clipping (the released
  layer has none). A non-finite or non-falling smoke is a FLAG before any g-check, and any fix (for example the
  paper's clipping) is a dated amendment before any S021 config.
  REGISTERED CHECKS, BEFORE THE FLAG IS WRITTEN (as S019's site D): the flag's author reads the raw source of the
  released layer and of its naive reference (fla/layers/path_attn.py, fla/ops/path_attn/naive.py) and records, value
  by value, whether this clause matches: rank 32 and no bias; the conv's kernel 3, SiLU and no bias, reset at
  sequence starts; the L2 norm per KV head; beta = 2 x sigmoid with a bias, per KV head; no RoPE; the product range
  s = j+1..i with H_i next to q_i; the scale 1/sqrt(64); the init. Any difference is amended into this clause by a
  dated entry before any S021 config exists, with the parameter count. Optional, recorded either way: the naive
  reference (plain torch) run on CPU in an isolated directory against the flag's three forms on small inputs.

KNOWN RISKS
  - Faithfulness: the harness's own PyTorch form, not the authors' Triton kernel (the same function; rounding differs);
    three forms are tested against each other, and REGISTERED CHECKS binds the values read through summaries.
  - PaTH is the only position signal; it was trained from scratch at 760M on 50B tokens in the paper, never at 5M or
    250M slots. At init each H_t is close to a projection, so far keys start attenuated.
  - bf16: the paper names instability of the cumulative product; the products run in fp32 here, and a divergence
    scores +inf (C7), never dropped.
  - Memory and speed are unmeasured: the T x T logits and the chunk scan in eager PyTorch are assumed x3 of base2m8's
    time (S005's forget path, also a T x T fp32 term in eager PyTorch, measured x2.26 of its own BASE); the smoke
    measures both.
  - The equal-total fit narrows the MLP by 23 units (4.7%); the REJECT wording names it.
  - P-020 says "in a few attention layers"; the released model puts PaTH in every layer with no RoPE, which is the form
    tested here; a hybrid (PaTH in some layers, RoPE in the rest) is not tested.
  - E3's SDs were measured in the varlen engine at micro 16; H1 runs the mask engine at micro 8 x accum 2 (S005's
    risk; base2m8 - base2 is reported).
  - NorMuon on PaTH's matrices (the harness's rule) where the authors used AdamW.
  - Loss is not behaviour (arch.md 1.4); P-020 is decided by its behaviour test. Starter mix and tok_v0_8k only.
