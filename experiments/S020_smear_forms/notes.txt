WHY
  S007 read the registered form (raw key, before QK-norm and RoPE, keys only) as loss-neutral at 8 layers. Two choices in
  that form were made without evidence: (1) smearing before QK-norm leaves the normalised key's scale unchanged, so the
  smear can only turn the key, not add the previous token's key at a learned weight (S007 KNOWN RISKS); after QK-norm
  the previous key is added at its normalised size and alpha sets its weight directly; (2) values unsmeared: KV-shifting
  attention shifts both, so a head can copy the previous token's value as well as match on its key. Each form is a
  one-flag change of S007's arm. smear_post is one mechanism against BASE (a smear of the normalised key), so V1 reads
  it against BASE. smear_kv is two mechanisms against BASE (S007's key smear and a value smear), so the value smear's
  own effect needs S007's form in the same batch: s020_raw (round 2, M1, for the reason S019 re-runs Canon-AC: without
  it the question would compare across batches and harness commits).
