WHY
  Vanilla attention needs 2 layers for induction and 1 with a smeared key (REPORT s4.1; LEDGER P-024 prior art:
  Olsson's smeared-key 1-layer in-context learning in small attention-only models; KV-shifting attention, arXiv
  2411.19574). Induction is the copying mechanism behind multi-turn recall (loop.md 4.2), and REPORT's limit 2
  (binding) needs multi-token keys, which a previous-token path makes cheap. P-024's win: "induction forms with one
  layer fewer, or earlier in training, at 5M on 2 seeds". The timing half is measurable now without RC-12 (C6 IND).
  S004 (Canon-AC) tests a heavier previous-token path; S007 is the minimal one, touching keys only. The two are read
  side by side in the report (no rule compares them).

QUESTIONS
  Q1 (decided, C7) Do smeared keys change held-out chat bits per byte at 5M, 250M slots?
  Q2 (P-024's own question; C7 only if an E3 Part 4d addendum gives IND an SD, else descriptive) Does induction form
     earlier in training (IND onset in tokens), and is final IND higher? Onset is compared at MATCHED LR (C6): from
     the screen runs if the arm's pick is g = 1; otherwise the arm also runs at g = 1 on the screen seeds for IND
     only (0.31 h per seed, never in a bpb verdict). Both onsets, onset_half and onset_abs (C6). The "one layer
     fewer" half would change the shape and is not tested here, and LEDGER P-024's first step (a toy, induction at
     1 vs 2 layers) is not run: a null here leaves that half open.

THE CHANGE (one flag)
  model.smear_key: true (new field; default false). Registered form: in every layer, for each KV head h, a learned
  scalar alpha_h; the raw key (after k_proj, before QK-norm and RoPE) becomes k_t + alpha_h * k_(t-1), where
  k_(t-1) is the previous position's raw key in the SAME document (zero at a document's first token). alpha_h
  starts at 0 (a constant: no RNG draw), so the arm starts as the exact BASE function. Values are not smeared (with
  kv_tie, which BASE does not use, V keeps the unsmeared key). Parameters: 8 layers x 3 KV heads = 24; total
  5,010,157 vs 5,010,133 (budget.py BASE count + 24). 1-D, so harness/optim.py split_params puts them in "scalar"
  (AdamW, no decay), at the embedding LR: E2 sets optim.embed_lr = optim.scalar_lr = r x eta, so alpha trains at
  g x r_5 x eta_5 (no new-module multiplier; the learned alpha is reported). The smear applies on EVERY path: the
  doc=None path (plain causal over the row, where the previous position is simply t-1), which data_prep/bpb.py
  uses (model(idx), no document ids) and so is where F(CHAT) is scored, the mask path and the varlen path.

KNOWN RISKS
  - A previous-token path through keys can be learned by BASE's own attention (induction forms anyway, in 2 layers);
    at 8 layers the gain may be only in timing, which is why Q2 is the ledger's reading.
  - IND is a random-token probe; earlier IND onset need not mean better conversational recall (Tier 0 after the
    lock is the check).
  - Smearing before QK-norm changes the key's direction but not its normalised scale; smearing after QK-norm would
    be a different arm, not tested.
  - Starter mix and tok_v0_8k only (C1 scope).
