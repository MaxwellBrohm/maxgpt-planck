Track K code (SPEC 14, Build phase). Written 2026-09-27. Nothing here was trained, queued or committed; no language
model was loaded. Tests: tiny CPU models only. No harness file was changed (K4 needs none: harness/budget.py already
solves an MLP width at a fixed total through attn_mult, fixed_d, fixed_layers and fit_mlp).

               foil in every item and a bystander entity (fams.fam_R by)
