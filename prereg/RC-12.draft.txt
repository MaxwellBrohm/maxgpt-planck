2. SCOPE AND BINDING RULES
  Target: conversational mechanics over the conversation's own context. Stored world knowledge is out of scope.
  Knowledge-free families: every gold is stated in the conversation (a user turn, a supplied table, or the model's
    own earlier reply). Only they enter a composite. Knowledge-bearing items (family K) are scored and reported
    separately and never enter a composite or a claim.
  L1 Every item is run through the fake scripted responders of s8 on the REAL items; the gated ones must fail.
  L2 No probe question, answer prefix, or user turn after the gold's statement contains that probe's gold (the
     generator tests go further: no question or prefix contains ANY candidate).
  L3 Every grader fails an empty reply, a loop, a hedge, a negation, a guess list, a reply in the user's voice, a
     wrong in-pool value, a shotgun list, an echo of the question, the stale value and a hypothetical, and passes a
     correct natural sentence. Each clause is mutation-tested (removed, a fixture goes red).
  L4 Knowledge-free and knowledge-bearing scores are never pooled.
  Dev text is Claude-written (a gold set under the D8 provenance rule). Dev and sealed share no template and no slot
  pool. Neither is ever training text: their user turns go into the 13-gram decontamination list (sealed: s13).
  E004 eval items are not reused (E004's fine-tunes saw its training streams); E001/E004 code and ideas are reused.

3. CONVERSATION FORMAT
  Every conversation has exactly 12 scripted user turns u1..u12. User text never depends on the model's replies.
  Own history: the harness sends u1, generates a1, appends a1 as the assistant message, sends u2, and so on to a12.
    Nothing from any gold, IDEAL reply or annotation is ever injected. The reply fed back is the decoded text after
    the stop rule (s4), leading and trailing whitespace stripped; it is stored verbatim with its stop reason (eos,
    eot, role, cap).
  Turn kinds (annotation): S statement of a fact; L same-type lure (a value of the probe's type bound to another
    holder or object); C correction; I standing instruction; O override of an instruction; Q request that makes the
    model commit to an answer (OWN); T passage or table (LOOKUP); D distractor filler; P graded probe; X second
    graded probe in the same conversation. Every D turn also carries asks (true or false), the hand label of its
    filler (F2, s17 OD6 follow-up (2)): false for a plain statement that asks nothing, true for a question or a
    request. It changes only which turns the loop rule counts as asking (s7); for every other purpose the turn is
    kind D.
  Distance: d = index(P) - index(S) in user turns, 1..11; for corrections dc = index(P) - index(latest C of the
    asked object).
  Probe placement: the main probe (for RECALL-abstain and LOOKUP, the LATER of the two probes: D16) is at u12 in 3/4
    of conversations and in the family's early range (usually u9-u11, fillers after) in 1/4, so "the last turn is
    the test" is not learnable from the format.
  Fillers (D): 90 dev fillers (45 how-to/why, 45 small talk/creative), each with a one-sentence IDEAL reply; no
    digit, name-like word, pool value, holder word or PERSIST rule word; 0 word 5-grams shared with E001/E004
    fillers; each used at most once per conversation. Filler replies are graded only by the loop and role-leak rules,
    never for content, so knowledge in a filler answer never moves a knowledge-free score. Each filler carries a
    hand label, read and set one by one (rc12/pools_fill_a.py, pools_fill_b.py): 50 questions (all 45 how-to/why
    fillers and 5 of the small-talk/creative ones), 20 requests (imperatives without a question mark, such as
    "Invent a silly holiday we could celebrate."), 20 statements ("The sunrise was really pretty today."). A D turn
    built from a statement has asks: false (904 of the 4,010 dev D turns; 3,106 have asks: true); the label is data
    copied by the builder and never inferred from the text or its punctuation at grading time (F2, s7, s17 OD6
    follow-up (2)).
  Length: user turns <= 35 words (LOOKUP tables <= 70). Budget: with every reply set to 50 words a conversation stays
    <= 1,800 tokens (proxy 1.35 x words + 4 per turn until a Planck tokenizer exists, then measured). Checked on every
    conversation (G7).
  Truncation (D13): if a rendered history exceeds (model context - 256), the harness drops the oldest WHOLE
    user/assistant pairs and logs it; a probe fails if any S, C, I, O, Q or T turn before it, or any of its source
    turns, was dropped from the history its reply was generated from. (SPEC said the probe's own S/C/I/Q/T turn; the
    rule used is a superset and can only lower a score.) With IDEAL replies the longest dev conversation is 572 proxy
    tokens, so a model with a 2k+ context never triggers it.
  Record (JSONL, one per conversation): id, split, family, cell, seed, turns [{i, kind, text, ideal, facts, vals,
    asks on D turns only}],
    probes [{turn, kind, grader, question, gold or gold_fn, candidates, pool, stale, holder, object_words, pair_id,
    d, dc, src, prefix, ideal, family fields}], meta.unit (mean | all | pair), knowledge flag. The full field list is
    the docstring of rc12/common.py. IDEAL replies are never shown to a model.

4. RENDERS AND DECODING
  Template render (primary for every model that ships a chat template): tokenizer.apply_chat_template(messages,
    add_generation_prompt=True), no system prompt, the model's default system behavior, enable_thinking=False for
    Qwen3-family models. Stop at the template's end-of-turn token(s) or eos; special tokens stripped on decode.
  Plain render (primary for models without a template; reported for every instruct model as a diagnostic, since
    rendering alone moved SmolLM2-135M recall from 0.15 to 0.70 in REPORT s3.2):
      User: <u1>\nAssistant: <a1>\nUser: <u2>\nAssistant:
    Generation starts after "Assistant:"; stop at eos or at the first newline followed by a role tag (User:,
    Assistant:, Human:, any case). Newlines inside a reply are kept and fed back as written.
  Planck: scored in its own shipped template and also in the plain render. Template = the harness ChatTemplate with
    role tokens, encoded with the trainer's own encode call, then <|assistant|>; no system turn, no BOS. Each
    checkpoint is scored with the tokenizer and template it was trained with, recorded by hash (s16). A role token
    in a Planck reply stops generation (stop "role") and is charged as a LEAK. History is fed back as text (the
    stripped decoded reply, re-encoded).
  Decoding (every model, Planck included): temperature 0.6, top-p 1.0, top-k off, repetition penalty 1.0 (off),
    max_new_tokens 256. All are passed explicitly, so a model's generation_config.json cannot change them (Qwen ships
    top_p 0.8, top_k 20, repetition 1.05). 3 sampling seeds per model; per-reply seed = md5(seed, conversation id,
    turn). Greedy is reported as a secondary result.
  Engines: vLLM in WSL2 on the 5070 wherever the architecture is supported; batched HF transformers for Doge,
    MaxGPT-3 and anything vLLM rejects. Conversations advance in lockstep batches (turn t of every conversation in one
    batch). A greedy HF-vs-vLLM parity check on 20 conversations per model family runs before any scored run. The
    locked file names one engine per model (OPEN, s16).
  Likelihood rows (diagnostic, P-004; NOT BUILT): every probe with a closed candidate set also gets a row on GOLDEN
    history (IDEAL replies) with a forced answer prefix from a separate prefix pool; right iff the gold's summed
    log-prob is strictly above every other candidate's (E004 lik.py rule; equal candidate token counts checked per
    tokenizer). Tier 0 margins are the per-checkpoint guard. Never in a composite or a claim.

6. GRADERS (pure Python, no model; rc12/graders.py, grade_text.py, grade_cues.py, grade_fmt_dyn.py, grade_role.py)
  G-VAL, strict value grader (closed candidate set). Right only if ALL hold:
    v1 non-empty, not degenerate (s7), stop reason is not the 256-token cap;
    v2 the gold is ASSERTED: some whole-word, case-insensitive mention (E004 value matching: grey/gray, number words)
       sits in a sentence that is not a question, not negated (a cue among not, no, never, neither, nor, without,
       cannot, none, any n't word, instead of, rather than in the 3 word tokens before it, or a negated copula right
       after it; the interjection "no," is not a negation), not hedged (sentence-scoped hedge list, extended by
       grade_cues.HEDGE_MORE and near_hedge: "I'd guess X", "X, if I recall correctly", "Maybe. It is X."), not in
       an example or an if-clause, not one side of "X or Y" (other side capitalized, a digit or a pool value), not a
       bare list line, not right after "than"; an unsure or deflecting phrase ("I'm not sure", "remind me") fails
       the whole reply;
    v3 no other candidate is asserted; a stale value of the asked object may appear only in a change phrase ("moved
       from X", "X was changed to") and only when the gold is asserted; any pool value NOT in the user turns up to
       the probe fails (a guess); a reply mentioning every candidate in any form fails (shotgun; COMPOSE exempt,
       D11);
    v4 assistant voice: the gold's sentence does not bind a user fact to the first person ("My cat is Biscuit",
       "I'm Marcus"; "my" within 3 words before an object or holder word). For assistant-held probes (OWN, "What
       did I call you?") the reverse is checked ("You picked X", "Your name is X");
    v5 no role leak (no role tag at a line start, no fake user turn) and not an echo: >= 80% of the reply's word
       4-grams copied from the probe question, OR the reply contains the whole question (4+ words) word for word
       (D8).
    Lenient twin (diagnostic only): the first candidate mentioned is the gold.
  G-ABS, abstain grader: an abstain cue (grade_text.ABS_CUE extended by grade_cues.ABS_MORE: "you haven't told me",
    "I don't think you've told me that", "That hasn't come up yet", "That list skips Thursday") AND no pool value
    mentioned at all. Lenient twin (reported): a value is allowed in a sentence that names its own correct holder. No
    echo clause (D12: no abstain question holds a cue, so the cue clause already fails every echo).
  G-FMT (PERSIST), 8 rules: caps (>= 90% upper case over >= 5 letters), lowercase (no capital, >= 5 letters), first
    word, closing phrase (last words, trailing punctuation ignored), one sentence, ends with "?", include word,
    square brackets. Every reply must also be fresh (E001 battery fresh()), have >= 4 words and not echo the user
    turn (D9), and must not stuff 3+ of the include-word pool (D21).
  G-DYN (OWN): parse the model's own Q reply as it sits in the history. pick: exactly one offered option asserted
    (G-VAL clauses), then G-VAL with that gold. list2: a numbered or bulleted list of exactly 3; the reply must hold
    every content word of item 2 (<= 4 words, 5-letter stems) and no content word unique to another item, the
    user's lure items included (D12). Source failure: the unit scores 0 and is counted.
  G-ROLEX (ROLE X), r1-r7: asserts no user fact in the first person, does not claim the user's name, states the
    given name when there is one, r5 no first-person sentence without "you" naming a person other than the
    assistant's given name, r7 at least one first-person word (D10).

    at or after the fact's turn), user voice ("my <holder>" with that holder's value), turn leak. Capture rate

7. LOOP RULE (pre-registered exactly; rc12/grade_loop.py), per reply r at turn t given the earlier replies:
  LOOP     some word 3-gram occurs >= 4 times in r; OR r, normalized (lowercase word tokens, punctuation and
           spacing ignored), equals an earlier reply of its equality set, at any length: if r answers a turn that
           asks something (kind P, X, Q, or D with asks: true; LOOP requests are P), every earlier reply of the
           conversation, whatever turn it answered; if r answers a statement turn (S, L, C, I, O, T, or D with
           asks: false), the earlier replies to asking turns (F1: an answer parroted on a statement turn); OR r has
           >= 12 words and >= 50% of its word 4-grams occur in ONE earlier reply (self-copy). The equality clause is
           OD6 (iii), ruled 2026-09-25, with F1 and F2 (s17 OD6 follow-up (1) and (2), decided 2026-09-25 by Claude
           under Max's standing permission, reversible before the lock); rc12/grade_loop.equality_set, loop_kind.
  Scope, stated plainly (second verifier review, 2026-09-26): the rule charges only these three things: a 3-gram
           said 4+ times inside one reply, a normalized VERBATIM repeat, and a copy of 12+ words sharing >= 50% of
           its 4-grams with one earlier reply. A short near-duplicate escapes, so "loops" in the Level A wording
           (s1, s10) means this rule, not every repetition. Measured on dev (fakes, notes STEP 8 round 2):
           PARROT_PLUS (PARROT with ", right" added to each parroted answer) loop 0.0052 (38 of 7,328, all
           self-copies: 11-word answers that the added word brought to 12), criterion met, answer-repeat 0;
           NEAR_D (a canned non-answer with the turn number appended, "Let me think about that one, number 4.",
           on every asking D turn) loop 0, criterion met, R_ungated 100. A near-duplicate rate reported beside the
           loop rate (never gated) is an open option for Max before the lock (s17 OD6 follow-up (4)).
  ACK-REPEAT (reported beside, never in Level A; the mark itself is never a flag) r answers a statement turn and,
           normalized, equals an earlier reply. Rates: over every reply, and over statement-turn replies. The
           equality clause never charges an acknowledgement said again after an acknowledgement; self-copy is
           unchanged, so an identical statement-turn reply of 12+ words is still a LOOP (and an ack-repeat), and one

  RUNAWAY  r stopped at the 256-token cap.
  EMPTY    r has no word characters.

9. METRICS, COMPOSITE AND LEVEL R (rc12/score.py, score_stats.py)
  Unit scores in [0,1]: a conversation (mean of its graded probes), a both-right conversation (RECALL abstain, ROLE,
  LOOKUP), or a pair of twins (BIND). Family score F_f(m) = mean over units, then over the 3 sampling seeds, then over
  training seeds.
  OWN gate (OD1 (b), ruled 2026-09-25): every run with OWN also runs OWN under --own-cf with the same sampling seeds
    and training seed. An OWN unit counts 1.0 only if it is 1.0 in BOTH runs (joined by conversation id); this gated
    OWN is the OWN family in R, the bootstrap, headroom and the sensitivity row. If any run lacks the cf twin of any
    of its OWN units, the gated OWN and R are undefined (None), never the ungated value. A twin must come from the
    same responder and render; a cf rewrite that did not take (own_cf.py cf_unswapped) scores its unit 0 and is
    counted in the report. The s1 words "on its own conversation history" (PLAN wording, kept) still hold for the
    claim: the gate can only remove OWN credit, the one edited assistant turn exists only in the --own-cf twin run,
    and every credited OWN unit was also right on the model's own history.
  Composite R(m) = 100 x unweighted mean of F_f over the composite families: RECALL, CORR, BIND, TWOHOP, PERSIST,
    OWN, TOPIC, ROLE, LOOKUP, LOOP (10 families, 10 points each). T0, K and COMPOSE never enter it. OD2 (a) keeps
    LOOP and OD4 (c) keeps F6-F8 out (both ruled 2026-09-25); the list is frozen at the lock after the headroom rule
    (s11).
  Paired difference D = R(Planck-{N}M) - R(Qwen2.5-0.5B-Instruct), template render, sampling T 0.6, on sealed.
  Bootstrap: 10,000 resamples. Each resample draws units within each family (stratified), with the SAME draw for both
    models (paired); training seeds resampled per model; sampling seeds resampled inside each drawn training seed
    (nested). Percentile 95% CI.
  Level R holds at a size when, on sealed, with >= 3 training seeds at that size: the CI's lower bound is >= -3
    points (proposal), T0 >= 0.90 (proposal), and the OOD-H wording rule of s1 is applied. It is claimed at the
    smallest size that meets it. The OOD-H wording rule is not implemented yet (needs OOD-H).
  Sensitivity row: the composite without the families where Qwen2.5-0.5B-Instruct is <= 0.05.
  Reported beside (never a claim): every cell; RECALL by d bin; CORR by reference form; PERSIST by rule; OWN
    source-fail rate; OWN from the own-history run alone and from the --own-cf run alone, and R_ungated (R with the
    own-history OWN); the count of cf rows whose rewrite did not take; lenient scores (OD7); likelihood rows;
    degenerate-type rates; the ack-repeat and answer-repeat rates (s7, OD6); capture rate; plain vs template render;
    greedy; K follow-up rate, control rate and gap; T0 failure list.
  Sealed size (PLAN sizing rule): from dev runs of Qwen2.5-0.5B-Instruct and the two baselines nearest to it,
    estimate the within-conversation correlation and the paired disagreement rate, simulate this analysis, and take
    the smallest count in steps of 100 (minimum 600, cap 1,500) with >= 80% power to show non-inferiority at -3 when
    the true difference is 0. If the cap is not enough, the margin stays at -3 and the achieved power is published.

11. HEADROOM RULE AND THE PERSIST BASE-RATE RULE (score_stats.headroom, persist_base_rates)
  After the dev baselines (core panel only, template render, mean of 3 seeds): a composite family or Level A key fails
  if EVERY core baseline scores <= 0.05 (floor) or EVERY core baseline scores >= 0.95 (ceiling). A failing family is
  rebuilt before the lock (harder or easier cells, same layout) or dropped from the composite with the reason written
  here. So a family where every baseline sits at the floor cannot be "passed" by matching the floor.
  PERSIST base rates: each rule's compliance share over every reply of every NON-PERSIST conversation; a rule above
  0.30 for any core baseline is dropped (proposal). one_sentence is expected to drop (plain replies comply). The drop
  list is written here at the lock. NOT RUN: no baseline has been scored.
