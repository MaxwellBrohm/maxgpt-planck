RECORD FORMAT (common.py docstring has the full list)
  turns[i]: i, kind (S L C I O Q T D P X), text (user), ideal (the IDEAL reply; never shown to a model), facts
  (annotations), vals (every RC-12 pool value in the text). probes[]: turn, kind P/X, grader VAL | ABS | FMT | DYN
  | ROLEX | LOOP, question, gold / gold_fn, candidates (in-context values of the type, in mention order), pool,
  stale, holder, object_words, pair_id, d, dc, src (user turns carrying the gold), prefix (likelihood rows),
  ideal, plus family fields: CORR b_values/alias; RECALL-abstain lure_holders; TWOHOP echo_value/hop1_turn;
  COMPOSE pool_values/diagnostic; PERSIST fmt {rule, arg, absent}; OWN gold_fn {type pick|list2, src_turn,
  options}, ideal_gold, ideal_items, lure_items; ROLE-X user_facts, aname; LOOKUP key, lure_value, other_value;
  K accepted, referent, ref_turn. meta.unit: mean (probes averaged), all (every probe must pass: RECALL
  abstain, ROLE, LOOKUP), pair (BIND: both twins).
  The IDEAL responder is simply "reply turns[i].ideal". IDEAL replies are distinct inside every conversation
  (tested), so the IDEAL cannot trip the equality branch of the loop rule.

CHOICES SPEC LEFT OPEN
  Value pools: 18 pools, pairwise disjoint (tested), "May" left out of MONTH. K answers (languages, capitals) share
  nothing with the knowledge-free pools. Names given to the assistant (ANAME) and user/lure names (PERSON) form
  one guess pool "name".
  RECALL/T0: gold frames never contain the question's "my <object>" run; lure frames bind the same type to
  another holder and reuse the question's words. X of the abstain cell is one stated fact of another type.
  CORR: U-diff latest forms pronoun / ellipsis / demonstrative / alias, 4 each; U-same full / head 8 each; B before
  A / after A's latest (with its own indirect correction) 8/8 in both U cells; C_twoslot latest forms full, head,
  pronoun, alias 4 each; an indirect correction always directly follows its own object's statement (tested).
  C_noupd: 8 of 16 get an ANCHOR: B's latest correction also names A as unchanged ("Actually, my college visit
  got changed to August, but nothing changes for my charity race."). Without it, "pick the statement naming the
  asked object" scored 1.00 on C_noupd (the E004 problem SPEC s0 names); with it, 0.50.
  BIND: owner and third-party use an intro turn naming both holders with no value, then pronoun-bound value
  statements with the SAME frame ("Mine is teal." / "Hers is red."); perspective crosses the words: the user's
  name comes with "call" ("Everyone calls me Elena."), the assistant's with "name" ("Your name is Kestrel from now
  on."), and "What's my name?" / "What did I call you?" alternate by pair. Twins differ only by swapping the two
  value statements (tested). Probe u12 in 3/4 of pairs, u10/u11 otherwise.
  TWOHOP: 4 schemas (door colour, class day, workplace city, event month) x 12; exactly one lure hop-2 statement
  echoes the question with a 3-word run and the gold's never does (tested).
  COMPOSE: number words (two..twelve), holder nouns as answers ("Which of my two pets is older?" -> "cat"); its
  pool is local (probe.pool_values). Diagnostic only.
  PERSIST rule words chosen to be rare in normal replies: first words Indeed/Behold/Ahoy/Greetings, closings
  "over and out" / "stay curious" / "that is all" / "until next time", include-words splendid/nifty/dandy/groovy.
  The base-rate drop rule (SPEC s3) still has to be run on baseline replies; "Greetings" and "Indeed" are the
  likeliest to hit it.
  OWN: pick categories boat, puppy, band, quiz team (8 each); IDEAL picks option 1/2/3 = 11/11/10. List topics 8 x 2.
  TOPIC: closed projects reuse the probes' own words ("sorted out", "up in the air"); the open project shares no
  word with the probes. Number of projects closed in a later turn cycles 0/1/2 inside each open position.
  LOOKUP: tables written "Key: value, ..."; three shapes (rota weekday->person, tour month->city, lunch menu
  weekday->food) x (old first / new first) x (asked old / new), 4 each.
  LOOP: 40 topics, 11 of 16 continuation requests per conversation, no repeat/summarize/again (tested).
  K: 16 "What language do they speak there?" + 16 "What's the capital city there?"; referent at u1-u6.
  Fillers: 90 new (45 how-to/why, 45 small talk/creative), IDEAL reply one sentence each. First drafts shared word
  5-grams with E001/E004 fillers in 37 of 90 (common stems like "what's a good way to"): all rewritten; now 0.

CHOICES SPEC LEFT OPEN
  Negation: a cue (not, no, never, neither, nor, without, cannot, none, any n't word, instead of, rather than) in
  the 3 word tokens before the value; the interjection "no," / "no problem," is not a negation; a negated copula
  right after also counts ("Friday isn't right"). Hedges are sentence-scoped (maybe, perhaps, possibly, probably,
  might, may be, could be, not sure, i guess, i think, i believe, i suppose, presumably, likely); unsure/deflect
  phrases fail the whole reply ("I'm not sure", "I can't remember", "remind me", "you haven't told me").
  "X or Y" counts when the other side is capitalized, a digit or a value of the probe's pool, except an "or" in a
  negated list after the value ("Friday, not Monday or Tuesday") or before a "but" ("Not A or B, but Friday").
  A value right after "than" is compared, not asserted. Stale values pass only in a change phrase (from, changed,
  originally, previously, earlier, before, used to, was, were, old before it; was/were/originally/.../no longer
  after it) and only when the gold is asserted; a negated other value is not an assertion. Guess = any mention of
  a pool value absent from the user turns up to the probe. Shotgun = every candidate mentioned in any form.
  User voice (v4): captures() on the gold or "my" within 3 words before an object word or the holder word; for
  assistant-held probes (OWN, "What did I call you?") the reverse ("You picked X", "Your name is X", "I called
  you X"). G-ABS cue list in grade_text.ABS_CUE; lenient ABS allows a value whose sentence names its own holder.
  G-FMT lowercase = no capital at all; closing = last words equal the phrase, trailing punctuation ignored.

  plain-text turn and not a leak). History is fed back as TEXT (the stripped decoded reply, re-encoded), the same
  protocol as the HF path; a byte-level reply that is not valid UTF-8 does not round-trip to the same ids.
  Tokenizer path: explicit --planck-tokenizer, else the config's data.tokenizer relative to --planck-config, else the
  checkpoint's stored config only if that path is absolute (a relative one is refused, not guessed).
