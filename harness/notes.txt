Conventions
  total = every stored parameter once (tied embedding once, loops/shared W_q,W_k once).
  embedding = V*d (2*V*d untied). body = everything else, final norm included.
  n_layers = unique CORE layers; unique = prelude + core + coda; depth = prelude + core*loops + coda.
  Solver ranking cost = |log(aspect/24)| + |log(mlp/(ratio*d))| + 5*|log(total/target)|,
  aspect = d / unique layers; hard limit tol=2%. MLP width may move up to 10% (step 8) to land
  on target (fit_mlp=0 turns that off). Looped arms get the same unique shape as dense arms.
  Value residual scalars (3) exist on every unique block that ever runs at effective depth > 0,
  so looping the core adds exactly 3 params (block 0). Init scales o_proj/down_proj by
  1/sqrt(2*effective depth).

Findings
  PLAN table's shapes counted exactly with nominal SwiGLU (8/3 d rounded to 32):
  5M 192x8 = 5.121M (+2.41%, outside 2%), 60M 512x18 = 61.207M (+2.01%), others within 2%.
  The PLAN used 12*d^2 per layer and ignored gates, norms and MLP rounding.
  Solver at vocab 8192 reproduces all six PLAN (d, layers, heads) with MLP widths
  488/688/864/1040/1336/1744 and errors under 0.2%.
  Vocab grid (head_dim 64): at 3M and 5M, vocab 16k-32k eats 63-84% of the total
  (5M@32k: d=128, 4 layers, 84% embedding). 3M@32k forces d=64 (1 head at head_dim 64).
  head_dim 32 gives a finer width grid at small sizes (see --head-dim 32).

STEP 2 (2026-09-24): trainer, optimizer, schedule, data. Done, 145 tests green (CPU only,
models under 0.1M params, about 4 s). No GPU was used.

Files
  blocks.py/model.py  + document masking: forward(idx, targets, doc=, pos=, reduction=).
                   doc (B,T) ids -> mask causal AND same-document (runs of equal ids, so a
                   reused id later in the row is a new doc); RoPE positions restart per doc.
                   doc=None keeps the fast is_causal path (bucket mode). reduction="sum" for
                   the trainer. Note: with RoPE, restarting positions is mathematically a no-op
                   under a doc mask (scores depend on relative position), so no output test
                   can see it; it is kept for inference parity.
  selftest.py      startup leak test (PLAN review 23): causal and document, each with grad and
                   under no_grad. Ratio = logit change where nothing may move / change where it
                   should. tol 1e-3 fp32, 3e-2 autocast. train.py runs it before training.
  optim.py         Ultra's Muon/NorMuon + cautious WD (copied, attributed). Groups: matrix
                   (NorMuon), embed (tok_emb + untied head, AdamW, own embed_lr/embed_wd),
                   scalar (norms, gains, VR scalars, AdamW, no decay). Every group has base_lr;
                   set_lr(opt, factor). kind: normuon | muon | adamw.
  schedule.py      WSD factor. full (1% warmup, linear decay to 0 over last 20%), trunk (never
                   decays; stable checkpoints at branch_points or branch_points_tpp), branch
                   (from a trunk stable ckpt at step s: decay_steps = s*f/(1-f) or explicit;
                   refuses warmup or decay-phase ckpts). factor(step) is the lr for that update.
  chat_template.py <|system|> <|user|> <|assistant|> <|end|> (+ optional <|tool|>, else tool
                   turns use tool_role). loss assistant: assistant content + its <|end|>; the
                   role token is prompt. loss all: every token. Per-turn "loss": false wins.
                   Turns carry "ids" (pretokenized) or "text" (needs data.tokenizer, HF json).
  sources.py       TokenShardSource (headerless uint16 .bin, EOT after each doc, Ultra format;
                   docs cut at EOT, long docs chunked to max_len). ChatJsonlSource (SPEC s11
                   records; conversations over max_len are DROPPED and counted, never cut).
                   Both loop over epochs with a (seed, epoch) shard order.
  packing.py       pack: FFD of whole items into seq_len rows + doc/pos, pad is its own doc.
                   bucket: one item per row, smallest bucket that fits, tokens_per_micro // L
                   rows per batch. Targets never cross items; pad targets -100.
  data.py          Loader: token-share mixing (deficit rule, exact by tokens), windows of
                   window_tokens, exact resume (window index, unit offset, cursors at window
                   start). stats(): drawn_<source> (tokens read into windows), dropped_long_*.
  runio.py         yaml with extends (Ultra cfg.py), prereg gate, runs.jsonl append (fsync),
                   atomic checkpoints: ckpt_* rolling (keep_last), stable_* and final_* kept,
                   latest.json.
  device.py        auto device (cuda, mps, cpu), precision auto = bf16 on cuda/mps, fp32 cpu;
                   MPS watermark env vars set before torch import. fp16+scaler NOT wired.
  trainer.py       step = grad_accum micro-batches; loss = sum over tokens / supervised tokens
                   of the whole step; clip 1.0; STOP file or SIGTERM saves and exits.
  train.py         CLI. python train.py RUN_DIR/config.yaml [--device cpu] [--max-steps N]
                   [--no-resume] [--require-committed]. Exit 2 = prereg refused.
  make_fake_data.py synthetic shards (ids: 0 pad, 1 eot, 2 sys, 3 user, 4 asst, 5 end, 6 tool).
  configs/sample_tiny/{config.yaml,prereg.yaml}  every key, commented; device pinned to cpu.

Record out (ChatJsonlSource / ChatTemplate read it unchanged)
  {"id": conv_id, "turns": [...], "pipeline": {every input field except turns, verbatim}, "source": {file,
  line, sha256 of the line}, "adapter": {version, admitted_nontrainable, tokenizer_sha256, n_tokens}}.
  Turn: role, text, loss, src_i (pipeline turn index, which events/gold notes/spans use), author, mask, spans,

  The pipeline system text becomes turn 0 (role system) so a token record renders with no tokenizer; there is
  no top-level "system" key (adding one would render the system text twice).

  NOT_TRAINABLE unless trainable is exactly true and blocked is empty; --allow-nontrainable admits and stamps

"mask" field. A raw pipeline record fed to ChatJsonlSource trains on the S3 wrong-value reply (checked on a
fake record: the masked turn's tokens are all supervised) and would read a literal <|end|> in text as control.
